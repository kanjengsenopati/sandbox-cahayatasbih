# Direktori Berkas APK CT-Mobile

Direktori ini digunakan untuk menyimpan berkas instalasi Android APK (`ct-mobile-latest.apk`).

- URL Publik (Staging): `https://sim.cahayatasbih.or.id/download/ct-mobile-latest.apk`
- URL Publik (Main): `https://aplikasi.cahayatasbih.or.id/download/ct-mobile-latest.apk`

Saat build APK baru telah dibuat (misal via GitHub Actions atau Android Studio), salin file APK hasil rilis ke:
`public/download/ct-mobile-latest.apk`
